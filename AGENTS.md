# monorepo-fullstack

Reusable fullstack starter (NestJS API + React admin web).

## Layout

pnpm 10 + Turborepo (`engine-strict`). Packages: `apps/api` (`@workspace/api`, NestJS 11 / Express 5 + Prisma 6 + Vitest 3), `apps/web` (package name is just `web`; Vite 8 + React 19 + TanStack Router/Query), `packages/contracts` (zod schemas + permission catalog), `packages/ui` (shadcn), `packages/{tsconfig,eslint-config}`.

## Commands

- Verify: `pnpm lint && pnpm typecheck && pnpm test` (then `pnpm build`). Smoke: `pnpm smoke` (uses `API_BASE_URL`, `SUPER_ADMIN_*`). Single package: `pnpm --filter @workspace/api <script>` / `pnpm --filter web <script>`.
- API dev: `pnpm --filter @workspace/api start:dev` (port 3000, Swagger `/api/docs` plus `/api/docs-json` and `/api/docs-yaml`, disabled when `NODE_ENV=production`). It watches `apps/api/src` and `packages/contracts/dist`; a contracts watch rebuilds `dist` so API restarts on contract changes. Web: `pnpm --filter web dev`.
- Single test: `pnpm --filter @workspace/api exec vitest run <path>`. Unit tests: `src/**/*.test.ts`; e2e: `test/**/*.e2e-spec.ts` via `test:e2e` (serial).
- E2E needs `docker compose up -d postgres_test` (5433) and the schema applied: `cd apps/api && DATABASE_URL=postgresql://app:app@localhost:5433/app_test pnpm exec prisma migrate deploy`. `test/support/test-app.ts` builds `DATABASE_URL` from `DB_TEST_*`, swaps mailer/object storage/throttler-Redis for in-memory fakes, sets `LOG_LEVEL=silent`; `resetDatabase` truncates — extend it when adding tables.
- Prisma (run in `apps/api`): `db:migrate` (`migrate dev`), `db:deploy`, `db:seed`. Seed uses `tsconfig.seed.json` (CJS) — plain `ts-node` fails under TS 6 / NodeNext. Seed syncs `PERMISSIONS` to the `permission` table, upserts system role "Super Admin" with every permission at scope `all`, and the user from `SUPER_ADMIN_*`.
- `contracts` resolves `src` for types/ESM but `dist` for CJS `require` (API is CJS): API `prebuild`/`prestart:dev` build it first; rebuild if API runtime sees stale contracts.
- `apps/web/src/routeTree.gen.ts` is generated by the vite plugin (committed, eslint- and prettier-ignored, don't edit). Regenerate with `pnpm --filter web exec tsr generate`. After adding/renaming routes, run `pnpm --filter web exec vite build` (or `dev`) before `typecheck`, otherwise `tsc -b` fails.
- shadcn: `pnpm dlx shadcn@latest add <name> -c apps/web` from repo root. Primitives land in `packages/ui/src/components`, blocks in `apps/web/src/components`, but hooks like `use-mobile` land in `apps/web/src/hooks` while `packages/ui` imports `@workspace/ui/hooks/...` — move them to `packages/ui/src/hooks`.

## Env

- Single root `.env` (copy `.env.example`); API loads `../../.env` relative to cwd, so run API scripts via `--filter` or from `apps/api`. Web: `apps/web/.env` (`VITE_API_BASE_URL`). `.env*` gitignored except `.env.example`.
- zod `EnvSchema` in `apps/api/src/common/config/env.schema.ts`; empty strings in optional vars count as unset. `DATABASE_URL` must stay a literal (Prisma CLI); `REDIS_URL` is derived from `REDIS_*`. `THROTTLE_LIMIT`/`LOGIN_THROTTLE_LIMIT`/`WEBHOOK_THROTTLE_LIMIT`/`LOG_LEVEL` are read straight from `process.env`. `SENTRY_DSN` enables Sentry; unset disables it.
- docker-compose: `postgres` 5432, `postgres_test` 5433, redis 6379, mailpit 1025/8025, minio 9000/9001. Ports may clash with containers already running on the host.
- Webhooks: Midtrans callback is `POST /webhooks/midtrans`, public, signature-verified, persisted in `webhook_event`, idempotent by `(provider,eventKey)`, and throttled by `WEBHOOK_THROTTLE_LIMIT` (default 300/min). Failed stored events can retry; already processed events return `{duplicate:true}`. Actual payment domain updates belong in `WebhooksService` where the ponytail comment is.
- Redis backs throttler storage and `CacheService` (lazy connect, connected before Redis throttler is used; fallback is in-memory when unavailable at boot). Role permissions cache at `role-permissions:<roleId>` for 60s; invalidate on permission replace/delete. MinIO and Midtrans are optional: no keys means `StorageService.enabled` / `PaymentGateway.enabled` false.

## Architecture

- API prefix `/api/v1`. Modules in `apps/api/src/modules/<m>/{domain,application,infrastructure,interface}`; domain ports are symbols bound to Prisma adapters in the module. Shared infra in `src/common/{config,prisma,rbac,audit,errors,http,pipes,ids,mailer,storage,payment,redis}`. Throw `DomainException` subclasses; `AllExceptionsFilter` + `ResponseEnvelopeInterceptor` wrap responses as `{data,meta?,error?,status}`. Lists return `Paged.of(items,total,page,limit)`. Validate with `ZodValidationPipe` + contracts schemas. Health endpoints: `/health`/`/health/live` liveness, `/health/ready` checks DB+Redis; `/metrics` exposes basic Prometheus-style Node metrics. Responses include `x-request-id` (incoming valid header echoed, otherwise generated). Update Swagger tags/ops for new endpoints.
- RBAC fails closed: global `APP_GUARD`s are only `ThrottlerGuard` + `JwtAuthGuard` (`@Public()` opts out). Guarded controllers add `@UseGuards(PermissionGuard)`; any route under it without `@RequirePermission("resource.action")` → 403 `PERMISSION_NOT_DECLARED`. Self-service routes (`/account`, `/auth/me`) use JWT only. `RolesModule` is `@Global` and exports `PermissionGuard`/`ScopeResolver`.
- Permission catalog lives only in `packages/contracts/src/permissions.ts` (`RESOURCES`, `ACTIONS`, `PERMISSIONS`); add a pair there (plus seed rerun) before using it. Scope `self|team|all` lands on `request.scope` (`@CurrentScope()`); `team` is denied unless a `TEAM_HIERARCHY_QUERY` provider exists.
- Login throttle: `@Throttle({default:{ttl:60_000,limit:loginThrottleLimit}})`, reading env `LOGIN_THROTTLE_LIMIT` (default 10). Global throttle respects `THROTTLE_LIMIT` (default 100).
- Role invariants (`RolesService`): `isSystem` roles can't be renamed, deleted or have permissions changed; roles with users can't be deleted; `users.manage`/`roles.manage` can't lose their last holder. Roles can set `requireTwoFactor`; Super Admin seeds with it enabled. Users can't change their own role or deactivate themselves; role change, deactivation and password change revoke all refresh-token families.
- One-time tokens (password reset, invite, email verify) live in `user_token` via `UserTokenService` (HMAC with `REFRESH_TOKEN_PEPPER`; OTP hash salted with userId, attempts capped at 5). Creating a user without `password` invites by email (`invited` = no password hash). Sessions = refresh-token families (UA/IP stored); access JWT carries `sid` so `/account/sessions` marks the current one.
- Security limits (password length, token/link TTLs, max code attempts) live only in `SECURITY_POLICY` (`packages/contracts/src/security.ts`); API enforces them, emails/UI display them via `formatDuration`. Don't hardcode durations.
- Announcements: `announcements.view|manage`; publishing (create as published or draft→published) pushes once (`notifiedAt` claim). Images via `POST /announcements/image`, magic-byte checked (`common/storage/image.ts`, never trust mimetype).
- Notifications: in-app row always written; push skipped when user `notificationPushEnabled=false` or app setting `pushNotificationsEnabled=false`. `/settings/public` (no auth) exposes `appName`/`logoUrl`/`loginNotice`/`supportEmail` for login/sidebar. App settings also include tagline/description/banner, support phone, address/district/city/province/country/postal code, latitude/longitude, currency, email footer, timezone and maintenance retention; image upload is the shared `POST /settings/image` (logo or banner). Transactional mail renders through `common/mailer/email-template.ts` (branded HTML: logo, tagline, button/code, footer, address) via `MailMessage.content`; plain `text` alone falls back to an unstyled wrap. `/system/status` and `/system/maintenance/cleanup` need `settings.manage`. Cleanup runs daily via `@nestjs/schedule`, uses a Postgres advisory lock, and deletes expired/used user tokens, expired/used refresh tokens, old processed webhooks and old read notifications.
- Users are soft-deleted (`deleted_at`; delete also deactivates and revokes sessions; restore via `POST /users/:id/restore`; lists hide deleted unless `?deleted=true`). Export `GET /users/export?format=csv|xlsx` (no deps: `common/csv.ts` with formula-injection guard, `common/xlsx.ts` minimal writer); import `POST /users/import` CSV `email,fullName,role` invites each row and reports per-row errors. `StreamableFile` bypasses the envelope and is audited as metadata only. App settings: single `app_setting` row `id="app"` validated by `AppSettingsSchema` (`settings.manage`).
- Auth: 15-min JWT access token in memory (web `token-store`); rotating HMAC-peppered refresh token in httpOnly `Secure` cookie at path `/api/v1/auth` (or body with `X-Client: mobile`); token reuse revokes the family. Role-required 2FA returns a 5-min challenge before issuing refresh tokens; TOTP secrets live encrypted in `user_two_factor`. First enrol returns 10 single-use backup codes once (SHA-256 in `user_backup_code`); login fallback `POST /auth/2fa/verify-backup`; `/account/two-factor` (status; `setup`+`enable` opt in when the role doesn't require it, login then challenges; `backup-codes`, `reset`, `disable` need current password; `disable` is 403 `TWO_FACTOR_REQUIRED` when the role requires 2FA). Mutations with `@Audited(action, entityType)` write `audit_log` (secrets redacted). Prisma tables snake_case via `@map`, IDs uuidv7 (`generateId`).
- Web: thin file routes in `src/routes` (`admin.tsx` = auth-guarded sidebar layout, `admin.*.tsx` pages); API calls in `src/features/<feature>/api.ts` through `authedRequest` (401 → single-flight refresh → retry); auth in `src/lib/auth-context.tsx` (`useAuth().can(resource, action)`). Hide nav/actions by permission; the API still enforces. Alias `@` = `apps/web/src`.
- Tailwind v4, no config: tokens in `packages/ui/src/styles/globals.css` (copied from reference; Plus Jakarta Sans + JetBrains Mono), imported once in `apps/web/src/main.tsx`. Prettier: no semicolons, double quotes, 80 cols, sorts classes in `cn`/`cva`.
