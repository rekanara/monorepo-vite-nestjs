# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting).

Include the affected area, steps to reproduce and the impact you observed. You should get a first reply within a few days.

## Scope

This is a starter template. Deployments built from it are owned by whoever runs them; set real secrets (`JWT_ACCESS_SECRET`, `REFRESH_TOKEN_PEPPER`, `SUPER_ADMIN_PASSWORD`, database and storage credentials) and never reuse the placeholder values from `.env.example` or the README.
